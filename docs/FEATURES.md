# 从连接配置到独立工作环境

[English](en/FEATURES.md) | [简体中文](FEATURES.md)

MC Proxy 将线路准备、出口核验、浏览器资料和恢复工具串成一条可见的工作流程。你可以从适合当前网络的入口接入同一个预期 ISP 出口，再复用自己的浏览器登录与工作设置。

## 第一次建立连接

1. **选择入口**：自建 VPS、导入受支持的 VPN 节点，或沿用已开启的外部 VPN。软件不附送线路账号。
2. **填写 ISP**：输入供应商提供的 HTTP CONNECT / SOCKS5 地址、端口与认证资料。保存前核验链路与观察到的出口；失败保留此前配置。
3. **准备环境**：按需要保存日常环境、选择工作环境和浏览器。Google Chrome 是默认方案，独立资料目录正常保留登录。
4. **建立连接**：在工作台查看实际路线、接管范围与核验结果。TUN 路径分别检查本地代理与系统默认网络出口，明确区分就绪、检查中和失败。

真实 TUN 需要 Windows 管理员权限。导入节点使用本项目 TUN 时，应先关闭可能冲突的外部 VPN；外部 VPN 兼容模式则需要其持续运行。

## 三种接管范围

| 模式 | 适合的接入方式 | 需要了解的范围 |
| --- | --- | --- |
| 全局 TUN | 希望系统新连接使用核验过的链路 | 单次系统检查不能代替每个应用的独立代理与既有连接核验 |
| 智能规则 TUN | 公共目标经 ISP，同时保留本地私网访问 | 具体例外以源码路由策略为准 |
| 显式应用代理 | 独立浏览器或主动配置代理的工具 | 未接入代理的普通程序不会自动受到覆盖 |

VPS 与导入节点路径支持 TUN；外部 VPN 兼容路径提供显式 HTTP 代理。当前路由以 TCP 为主，非 DNS UDP 不作为通用转发能力。

## 一个用途，一个浏览器环境

用户浏览器环境保存独立的 Cookie、网站存储与常用入口，用于区分个人、项目或不同账号的日常工作。默认 Chrome 使用独立资料目录，不覆盖日常 Chrome 个人资料；也可选择 Edge 或匹配的可选指纹运行时。

- 重用同一环境时保留已有资料，网站仍可能因自身会话过期要求重新登录。
- 每个环境固定浏览器类型，切换前正常关闭当前受管浏览器；一次运行一个环境。
- 刷新资料、恢复归档与移除环境卡片是不同操作。移除卡片不等于安全擦除登录数据。
- 指纹选项提供身份与资料管理，不保证网站无法识别或账号不会受到限制。

## 环境设置与可控恢复

工作设置覆盖时区、语言与区域相关选项，提供国家预设、自定义保存、日常环境恢复和原始快照记录。部分设置未匹配时保留已成功的项目并列出未完成项；语言包、系统权限和应用缓存可能影响最终表现。

结束代理、恢复系统环境与处理旧网络保护是独立动作。关闭主窗口会收起至托盘，后台会话继续；需要退出时使用客户端的安全退出入口。

## 遇到问题时

工作台与诊断页将代理出口、系统网络、目标 TLS、浏览器观察和应用启动分别显示。错误出现在当前操作页面或抽屉内，不把一次 HTTPS 可达直接表述为网站账号或模型业务可用。

故障报告在本地生成，只导出固定范围的脱敏信息；分享前仍应预览。程序保留旧断网锁检查与独立修复工具，**当前暂停创建新断网锁**，不能将它视为持续断网保护。核心停止后普通应用可能恢复直连。

开发演示和资源前提见 [开发说明](DEVELOPMENT.md)，资料与报告边界见 [安全说明](../SECURITY.md)。


## 适应不同桌面的窗口布局

横向、标准、纵向三种预设可以点击整张卡片切换，也可拖动窗口边缘调整大小。窄窗口保留完整工作流程，键盘焦点、高对比和减少动态效果提供相应适配。
